Unified Data & API Architecture Flow

1 Common Intents (First Truth)

Every assistant query searches /data/intents.json first. Predefined questions, spacecraft rules, and material physics return instant, verified answers with zero external API calls.

2 OpenAI Serverless Fallback

If an inquiry cannot be answered from the intents file, the frontend securely queries /api/openai. Keys remain strictly server-side in environment variables.

3 External API Encapsulation

All external services (such as NASA DONKI space weather) are encapsulated under /api/donki. Frontend pages consume serverless endpoints rather than scattered client calls.
